# Bundled variable fonts

Only **MiSans VF** ships with TokenBar (`MiSansVF.ttf`, ~19 MB).
License: Xiaomi font IP license, see `NOTICE-MiSans.txt`.
Source: https://hyperos.mi.com/font/zh/

The other supported families stay in the picker but are install-guided.
Selecting an uninstalled row opens the official download:

| Picker name | Install file | Official page |
| --- | --- | --- |
| Source Han Sans VF | `SourceHanSansCN-VF.ttf` | [adobe-fonts/source-han-sans Subset](https://github.com/adobe-fonts/source-han-sans/tree/release/Variable/TTF/Subset) |
| Noto Sans CJK VF | `NotoSansSC-VF.ttf` | [notofonts/noto-cjk Sans Subset](https://github.com/notofonts/noto-cjk/tree/main/Sans/Variable/TTF/Subset) |
| Source Han Serif VF | `SourceHanSerifCN-VF.ttf` | [adobe-fonts/source-han-serif Subset](https://github.com/adobe-fonts/source-han-serif/tree/release/Variable/TTF/Subset) |
| Noto Serif CJK VF | `NotoSerifSC-VF.ttf` | [notofonts/noto-cjk Serif Subset](https://github.com/notofonts/noto-cjk/tree/main/Serif/Variable/TTF/Subset) |

After Windows install, use 「我已安装」 in the dialog, or reopen Settings.
