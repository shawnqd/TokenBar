# 维护与使用手册

## 1. 这是什么

这是一个本地使用的模型套餐额度看板。

它的主要作用不是替你自动登录各个平台，也不是替你自动充值，而是把你当前拥有的套餐、额度、模型、配置状态和风险统一整理在一个地方，方便每天决定先用哪个。

## 2. 你日常需要做什么

### 每天

1. 打开总览页
2. 看今天推荐使用哪个套餐 / 模型
3. 看有没有快到期、额度低、配置失效、高风险的平台

### 新增一个平台或套餐时

1. 添加平台
2. 添加套餐
3. 填 Base URL
4. 选择当前模型
5. 填到期时间和额度桶
6. 标记 API Key 状态
7. 写风险备注

### 换电脑时

1. 在旧电脑导出
2. 把导出文件拷到新电脑
3. 在新电脑导入
4. 重新检查本地配置状态

## 3. 什么不会被保存

系统不应保存：

- 真实 API Key
- Cookie
- 账号密码

系统只保存：

- API Key 状态
- Base URL
- 模型
- 套餐和额度信息
- 风险备注

## 4. 常见状态说明

### API Key 状态

- `未配置`：本地没有检测到相关配置
- `已配置`：本地检测到配置，但不代表一定可调用
- `失效`：曾经有配置，但当前已确认不可用
- `待验证`：用户手动填写或导入后，还没有确认
- `未知`：暂时无法判断

### 风险等级

- `低`：一般提醒，不影响当前使用
- `中`：建议尽快关注
- `高`：可能影响今天或近期使用

## 5. 出现异常时怎么处理

### 首页没有数据显示

先检查：

1. 是否至少录入了一个平台和一个套餐
2. 是否有额度桶
3. 是否有到期时间或重置时间

### 某个平台显示未配置

说明系统没有在本地发现配置，或者配置路径失效。

你可以：

1. 手动标记状态
2. 检查本地环境变量或配置文件是否存在
3. 重新执行配置状态检测

### 导入后数据不对

先检查：

1. 导入文件是不是本工具导出的结构
2. 是否选择了覆盖导入
3. 是否有字段缺失

如有问题，优先回滚到导入前备份。

### 自动适配失败

这是允许的。

处理原则：

1. 自动适配失败不能影响手动台账
2. 先继续用手动管理
3. 再单独修 Provider 适配

## 6. 维护者注意事项

维护者在处理问题时：

1. 不要要求用户导出真实密钥
2. 不要在日志里打印 Bearer、Cookie、账号密码
3. 不要把网页登录抓取当成 P0 必需能力
4. 不要因为某个 Provider 失效就阻塞整个工具
